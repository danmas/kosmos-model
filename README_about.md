# О проекте Kosmos Model Gateway

**Kosmos Model Gateway** — это унифицированный API-шлюз и веб-интерфейс для работы с различными LLM-провайдерами (Groq, OpenRouter, GigaChat, Z.AI/Direct).

## Суть проекта
Проект решает проблему фрагментации доступа к нейросетям, предоставляя **единую точку входа** с полной поддержкой протокола OpenAI. Это позволяет использовать любые модели (Llama 3, GPT-4, Claude и др.) в существующих инструментах (LangChain, OpenAI SDK) без изменения кода, прозрачно переключаясь между провайдерами.

## Ключевые возможности
*   **Единый OpenAI-совместимый API:** Стандартные эндпоинты `/v1/chat/completions` и `/v1/models` с поддержкой стриминга (SSE).
*   **Умная маршрутизация:** Система алиасов (`FAST`, `RICH`, `CHEAP`) позволяет агентам запрашивать "быструю" или "умную" модель, не заботясь о конкретной реализации.
*   **Агрегация провайдеров:** Объединяет скоростные (Groq), дешевые агрегаторы (OpenRouter) и корпоративные (GigaChat) решения.
*   **RAG (Retrieval-Augmented Generation):** Интеграция с векторными базами для поиска по контексту документов.
*   **Управление и Наблюдаемость:** Веб-интерфейс для управления доступными моделями, мониторинга затрат и просмотра истории запросов.

## Для чего это нужно
Проект служит фундаментальным слоем (Backend-for-Frontend / Middleware) для экосистемы AI-агентов, обеспечивая их стабильным, контролируемым и экономически эффективным доступом к языковым моделям.
